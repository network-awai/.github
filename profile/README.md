# Awai Network

**Use. Create. Share.**

We're building an open, distributed network for people and agents — connecting AI, apps, work, and the people who provide computing resources.

人と agent のための、オープンな分散ネットワークをつくっています。使う人、つくる人、計算資源を提供する人が、AI・アプリ・仕事を通じてつながる場所へ。

[Explore awai.network](https://awai.network) · [Join / 参加する](https://awai.network/join/) · [Models on Hugging Face](https://huggingface.co/awai-network)

## Building in the open

- [**Awai OS**](https://github.com/network-awai/awai-os) — the Awai operating environment, with platform and node work tracked in the repository.
- [**Tatara**](https://github.com/network-awai/app-tatara) — distributed CI/CD for Awai.
- [**App design**](https://github.com/network-awai/cloud-kotoba-dds) — task-first interaction contracts and application design guidance.
- [**More repositories**](https://github.com/orgs/network-awai/repositories?type=public) — browse the public projects.

Awai is under active development. Availability and verification vary by component; see [node readiness](https://awai.network/network/readiness/) and each project's documentation for current status.

Awai は開発中です。利用できる機能や検証状況は構成ごとに異なります。[構成と完成度](https://awai.network/network/readiness/?lang=ja)と各プロジェクトの記録をご覧ください。
